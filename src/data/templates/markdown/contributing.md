# Student Open-Source Guide & Contribution Rules

Congratulations on working on this project! If you want to share your learnings, improve the rules, or join other student builders, here is how to contribute back to the student developer ecosystem.

## 1. How to Contribute to Open Source

If you are new to contributing to GitHub repos, follow this quick-start pipeline:
1. **Fork the Repo**: Click the "Fork" button on the top-right of the repository page to create a copy in your own GitHub account.
2. **Clone Locally**: Clone your fork to your computer:
   \`\`\`bash
   git clone https://github.com/your-username/repo-name.git
   \`\`\`
3. **Create a Branch**: Create a descriptive feature branch:
   \`\`\`bash
   git checkout -b feat/my-new-feature
   \`\`\`
4. **Commit Changes**: Make clear, atomic commits using semantic messages:
   \`\`\`bash
   git commit -m "feat: add input validation for login schema"
   \`\`\`
5. **Push and PR**: Push your branch to GitHub and click "Compare & pull request" on the original repo page.

## 2. Share Your Guardrails with Brokeflow

Did you discover an AI agent rule that saved you hours of debugging? Or did a model break a stack convention and you figured out how to write a rule to prevent it? Let the community know!
- **Star and Fork Brokeflow**: https://github.com/brokeflow/brokeflow
- **Submit a Rule Proposal**: Create an issue detailing your stack, tool, and the rule that worked: https://github.com/brokeflow/brokeflow/issues
- **Discussions Board**: Post your custom \`AGENTS.md\` setups and stack templates to share them with other student developers.
